- genai-schema: schema generated by LLM on OpenAPI fragments. several of these are terribly incomplete and inaccurate.
- openapi-components: OpenAPI specifications created from main specification for specific capabilities of the API. This is done using the command line tool `redocly` as described below.
- concert-openapi.yaml: Complete OpenAPI specification for concert API.


Current build process:

1. Create a directory for the component you wish to build.
1. Use redocly to split the large openapi spec.
    ```
    redocly split ../../concert-openapi.yaml --outDir .
    ```
1. Edit the openapi.yaml file redocly generates when splitting the large spec to only include the paths you wish to generate schema for.
1. Use the redocly bundle command to build the new component spec. e.g.
    ```
    redocly bundle openapi.yaml -o access-management.yaml --remove-unused-components
    ```
    (unsure if the "remove-unused-components" flag matters here.)
1. Delete the `components` and `paths` directories. (leaving the `openapi.yaml` file so we can easily see which paths were included.)
1. Feed that component spec to genai to generate the StepZen spec.
1. Edit the GenAI generated StepZen spec for accuracy, etc.
